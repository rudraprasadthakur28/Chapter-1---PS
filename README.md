# Python Practice Set 1

This repository contains my solutions to **Python Practice Set 1**. The questions focus on basic Python programming, using the REPL, installing and using external modules, working with directories using the `os` module, and adding comments to Python programs.

## Questions Covered

### 1. Print a Poem

Write a Python program to print the **"Twinkle, Twinkle, Little Star"** poem.

### 2. Table of 5 Using REPL

Use the Python **REPL (Read-Eval-Print Loop)** to print the multiplication table of 5.

### 3. External Module

Install an external Python module and use it to perform an operation of your choice.

### 4. Directory Contents Using `os`

Write a Python program to display the contents of a directory using the **`os` module**. Find the appropriate function online.

### 5. Add Comments

Add comments to the program written for **Question 4** to explain the code.

## Topics Practiced

* Basic Python syntax
* `print()` function
* Python REPL
* External modules
* `import`
* `os` module
* Directory handling
* Python comments
